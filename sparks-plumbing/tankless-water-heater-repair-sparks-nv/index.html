    Noritz Tankless Water Heater Repair in Sparks, NV

    Noritz heaters hold up well, but their flow sensors and vent connections still wear out. A code 90 points to combustion trouble, often a dirty fan or a restricted intake.     Rinnai Error Code Repair in Sparks

    Rinnai owners usually call about a code 10, which points to an air supply or exhaust blockage.
